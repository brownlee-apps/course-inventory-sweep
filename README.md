# Course Inventory Sweep

The Course Inventory Sweep is the page Bossier Parish Community College's academic divisions use to review every active academic course before the move to the Watermark catalog. It runs entirely in the reviewer's browser. It stores nothing, and nothing a reviewer enters is sent to this site. Each course ends in a PDF report and a submission file saved to the reviewer's own computer, which the reviewer then attaches to the Office of Academic Affairs' submission form.

`index.html` is built from the Sweep's rebuild kit, kept by the Office of Academic Affairs. Edit the kit's source and rebuild rather than editing this file by hand.
